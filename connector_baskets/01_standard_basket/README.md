# Standard basket

Generic connector basket for the R2metal implantation system. It fits many high-density connectors and is the basket supplied with the system.

![Standard basket](../images/standard_basket.jpg)

## Files

| File | Use |
| --- | --- |
| `R2_metal_system_standard_basket.stl` | Ready to print |
| `R2_metal_system_standard_basket.step` | Neutral CAD format, for modifying in any CAD program |
| `R2_metal_system_standard_basket.f3d` | Fusion 360 source file |
| `R2_metal_system_standard_basket_Drawing.pdf` | Dimensioned drawing |

## Key dimensions

| Dimension | Value |
| --- | --- |
| Overall width | 14 mm |
| Connector opening | 7.5 mm |
| Arm depth | 9 mm |
| Rod bore | Ø1.75 mm |
| Set-screw thread | M3 × 0.5, 6H |

## Printing

Print at 100% scale and remove all support material. Cut the thread with an M3 tap or use a threaded insert (preferred for FDM prints).

See the [main README](../README.md) for how the basket system works and how to customise it.
